# 阶段 Skills

每个文件是一个阶段的可移植提示词模板，框架无关。可以直接作为 system prompt 片段、Agent skill 或项目规则加载。

统一结构：

| 段 | 作用 |
|---|---|
| 角色 | 这一阶段 Agent 是谁 |
| 输入 / 输出 | 与上阶段的契约 |
| 步骤 | 执行顺序 |
| 门禁 | 什么条件下才能推进 |
| 停止条件 | 什么时候必须回退或请求人工 |
| 工具槽位 | 需要接入的能力，不绑定具体产品 |
| 留痕 | 写到哪个过程产物 |

占位符用 `${...}`，在 `reqflow init` 时替换。任何一段都可以按你的组织口径改写——它们是提示词，不是代码。
